# President Simulator - Demo

Application web autonome en francais.

## Ouvrir le jeu

Le serveur local lance pendant la creation sert le jeu ici :

http://127.0.0.1:4173/index.html

Il est aussi possible d'ouvrir directement `index.html` dans un navigateur moderne.

## Boucle de jeu actuelle

- Creation d'un candidat fictif.
- Campagne presidentielle en temps reel avec meetings, debat, alliances, programme et risques de vie privee.
- Election de second tour.
- Mandat presidentiel si victoire.
- Tableau de bord, budget detaille, fiscalite, entourage, voyages diplomatiques, fronts militaires, cybermenaces et crises.
- Niveau global sur 100 base sur popularite, succes, stabilite, influence, securite et contraintes de dette/guerre.
- Objectifs recurrents, progression XP et sauvegarde locale.

## Condition de victoire proposee

Finir le mandat compresse avec un heritage republicain majeur :

- niveau global au moins 85 ;
- stabilite au moins 58 ;
- succes au moins 68 ;
- popularite au moins 43 ;
- dette sous 132 % du PIB ;
- aucun theatre militaire effondre.
